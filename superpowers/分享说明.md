# Superpowers skill 集 · 分享与安装说明

> 群发用。拿到包的同事照着做,3 分钟装好。不想用了也能一键卸载。

---

## 这是什么

一套让 AI 编程工具(Claude Code / Qoder / Trae)"按规矩干活"的 skill。装好后,对 AI 说一句 `/superpowers`,它后续写代码就会:**先问清需求 → 拆任务 → 先写测试 → 系统化调试 → 完成前先验证**,而不是闷头乱写。详情看 `guide/Superpowers我司落地指南.docx`。

---

## 安装(三种方式,任选一种)

### 方式一:压缩包(最简单)

1. 解压收到的 `superpowers-skills.zip`,得到 `superpowers/` 文件夹。
2. 在文件夹里运行安装:

```bash
# Mac / Linux / Windows Git Bash
cd superpowers
bash install/install.sh                     # 全局:装了哪个 IDE(Claude Code/Qoder/Trae)就往哪个里装
bash install/install.sh --project /你的/项目   # 只装到某个项目(含项目引导)
bash install/install.sh --with-all          # 强制三端都装(即使某 IDE 还没装过)
```

```powershell
# Windows PowerShell
cd superpowers
.\install\install.ps1                       # 全局(自动适配已装的 IDE)
.\install\install.ps1 -Project 'D:\你的\项目'
.\install\install.ps1 -WithAll              # 强制三端
```

```cmd
:: Windows 批处理(不想装 Git Bash、也不想碰 PowerShell,双击 .bat 即跑)
cd superpowers
.\install\install.bat                       # 全局(双击即跑)
.\install\install.bat --project D:\你的\项目
.\install\install.bat --with-all
```

> 全局模式不建空目录:你电脑没装过的 IDE 不会被创建。想预装用 `--with-claude` / `--with-qoder` / `--with-trae` / `--with-all`。一个 IDE 都没装过时脚本会提示并退出,不写任何东西。

### 方式二:git clone(团队推荐,方便更新)

```bash
git clone <内网仓库地址>/superpowers.git
cd superpowers
bash install/install.sh
```

### 方式三:远程一行(无需手动 clone,需仓库已托管)

```bash
# 一行装到全局
curl -fsSL <内网仓库>/raw/main/install/remote-install.sh | bash

# 或装到某项目
curl -fsSL <内网仓库>/raw/main/install/remote-install.sh | bash -s -- --project /你的/项目
```

> 用 Qoder(阿里)或 Trae(字节)?给命令加 `--with-qoder` / `--with-trae`,或 `--with-all` 一次性三端。全局和项目模式都生效。

## 装完怎么用

1. 在 Claude Code 里开个会话,输入 **`/superpowers`** 回车(Qoder 里说"启用 superpowers")。
2. 再发你的需求(如"给用户模块加个批量导出功能")。
3. AI 会**先问你问题**(格式?数据量?权限?),而不是直接写码——说明开关生效了。
4. 想关掉:说"停用 superpowers"。

## 不想用了?一键卸载

只删本套装进去的东西(6 个 skill + `/superpowers` 命令 + 引导段),**不碰你自己写的任何内容**。

```bash
# 有文件夹的:直接跑卸载脚本
bash install/uninstall.sh                          # 卸全局(Claude Code)
bash install/uninstall.sh --with-all               # 连 Qoder / Trae 一起卸(全局)
bash install/uninstall.sh --project /你的/项目 --with-all   # 卸某项目(三端)
```

```powershell
# Windows PowerShell
.\install\uninstall.ps1                             # 卸全局
.\install\uninstall.ps1 -WithAll                   # 三端一起卸
.\install\uninstall.ps1 -Project 'D:\你的\项目' -WithAll
```

```bash
# 远程装的(没有本地文件夹),一行卸载:
curl -fsSL <内网仓库>/raw/main/install/uninstall.sh | bash -s -- --project /你的/项目
```

> 先看看会删什么、不真删?加 `--dry-run`(PowerShell 加 `-DryRun`)。

## 常见问题

- **敲 `/` 看不到 `superpowers` 命令?** 命令没装上。全局安装应在 `~/.claude/commands/superpowers.md`;项目级需在项目目录下启动 Claude Code。
- **Qoder / Trae 里 `/superpowers` 没用?** 这两个 IDE 没有 slash 命令,直接说"启用 superpowers"(靠 `superpowers` skill 触发)。
- **装完 AI 还是不先提问?** 检查项目根有没有 `CLAUDE.md` 引导段(哨兵 `<!-- superpowers-sinosafe:begin -->`),或 `.qoder/rules/superpowers-sinosafe.md`、`.trae/rules/superpowers-sinosafe.md`。
- **装哪了 / 怎么看版本?** skill 在 `~/.claude/skills/`、`~/.qoder/skills/`、`~/.trae-cn/skills/`(全局)或 `<项目>/.claude/skills/` 等(项目)。

有问题:在内网 GitLab 仓库提 issue(维护者会收到通知)。
